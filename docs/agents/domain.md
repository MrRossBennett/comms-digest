# Domain Docs

This is a single-context repository.

## Read Before Exploring

- Read `CONTEXT.md` for the canonical Comms Digest language.
- Read relevant decisions under `docs/adr/` before changing an affected area.

If either location is absent, proceed without requiring it to be created.

## Use The Glossary

Use terms as defined in `CONTEXT.md` in issues, tests, code, and documentation. Avoid synonyms that the glossary explicitly rejects.

If a required domain concept is missing or ambiguous, note it for a future `grill-with-docs` session instead of silently inventing conflicting language.

## Respect Decisions

Surface any proposed change that contradicts an existing ADR rather than silently overriding it.
