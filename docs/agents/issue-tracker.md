# Issue tracker: GitHub

Issues and PRDs for this repository live as GitHub issues in `MrRossBennett/comms-digest`. Use the `gh` CLI for all operations.

## Conventions

- Create an issue with `gh issue create`.
- Read an issue and its comments with `gh issue view <number> --comments`.
- List issues with `gh issue list` and request JSON fields when structured output is useful.
- Comment with `gh issue comment <number>`.
- Apply or remove labels with `gh issue edit <number>`.
- Close with `gh issue close <number>`.

Run commands inside the repository so `gh` infers the correct remote.

## Publishing

When a skill says to publish to the issue tracker, create a GitHub issue in this repository.
